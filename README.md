# isu-landing (CheckWary)

A premium, creative **dark-mode** Bootstrap 5 landing page template for the fictional cybersecurity product **CheckWary**.

## Highlights
- Bootstrap 5.3 via CDN
- Dark-first design with layered gradients + glass panels
- Small interactive **Risk Scan demo** (range slider updates score + advice)
- No external images (inline SVG)

## Run
Open `index.html` in your browser.
